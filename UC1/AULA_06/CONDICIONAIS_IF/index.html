Uso dos condicionais IF no JavaScript

O condicional if é utilizado para executar um bloco de código apenas quando uma condição for verdadeira. 

let idade = 18;

if (idade >= 18) {
    console.log("Usuário maior de idade");
} else {
    console.log("Usuário menor de idade");
}

Nesse exemplo, o sistema verifica se a idade é maior ou igual a 18. Caso seja verdadeira, o primeiro bloco será executado.
