# SISTEMA DE RH

## Problema
A empresa controla o numero de funcionarios 
de ferias e de jornada
 
## Objetivo
criar um sistema que possa organizar e monitorar , os horario de ponto,
e numero preciso da entrada e saída de cada funcionario

## Usuários
funcionarios
gestor
estagiarios

## Regras de Negócio
1- funcionario pos 1 hora a 30 minutos de almoço (limite maximo estabelecido é 10 minutos).
2- caso funcionario passe de 10 minutos estabelecidos sera descontado 0,50 centavos por minuto.
3- funcionario não pode tira 30 dias de ferias seguidas.
4- so sera permitido entrar em ferias a cada 15 dias.
5- funcionarios do mesmo setor não podem tirar ferias ao mesmo tempo .

## Requisitos Funcionais
1- O sistema deve permitir cadastrar a entrada dos funcionarios.
2- O sistema deve permitir cadastrar a saida dos funcionarios.
3- O sistema deve permitir registrar o horario de saida e entrada de cada funcionario. 
4- O sistema deve permitir deve indentificar a ausencia do funcionario.
5- O sistema ao intentificar faltas e atrasos é permitido descontar.

## Requisitos Não Funcionais
1- O sistema deve ter interface simples.
2- O sistema deve funcionar em computadores e celulares.
3- O sistema deve proteger os dados dos usuários.
4- O sistema deve carregar rapidamente.
5- O sistema deve ter layout responsivo.
